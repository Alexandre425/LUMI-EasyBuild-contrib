# SZ3

SZ3 is a thouroughly modified version of SZ (SZ2 is also considered SZ)
and it appears that it can be used together with SZ in software packages
(at least ADIOS does so) which is why we have switched the package name
to `SZ3`. Spack also makes it a separate package.

-   [SZ3 on GitHub](https://github.com/szcompressor/SZ3)

    -   [GitHub releases](https://github.com/szcompressor/SZ3/releases)


## EasyBuild

-   There is no support for SZ3 in the EasyBuilders repository when we started development.

-   [sz3 in Spack](https://packages.spack.io/package.html?name=sz3)
